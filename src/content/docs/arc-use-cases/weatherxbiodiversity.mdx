## About the original publication


## This use case

- Reproduce the data retrieval and processing pipeline described in the paper
- Adopt the published (R) scripts provided by the publication to python
- Wrap / annotate the scripts using CWL for FAIR annotation and reusability
  - provide docker

## The example ARC

The [example ARC](https://git.nfdi4plants.org/lifewatch-eric/WeatherXBiodiversity_Soroye2020)

  2. Install cwltool
  3. Install docker
  4. (Optional) Register GBIF account
