You might want to add file names to a column, especially "Input" or "Output". Since typing them in name by name could get quite tedious, you can copy the file names with the file picker instead. For this, click the 'File Picker' button in the <a href={SwateOverview.src} target="_blank">Sidebar</a>. and select "Pick file names". The file names will appear in the sidebar and you can modify their order. Once your files are listed in the correct order, click on "Insert File Names" to directly paste their names into the selected column.
