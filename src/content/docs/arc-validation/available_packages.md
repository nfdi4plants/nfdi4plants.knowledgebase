## Additional Validation Packages

There a number of different validation packages available depending on what you want to validate your ARC against. You can check out the full validation package registry [here](https://avpr.nfdi4plants.org/packages) or in ARCitect. Below are some that may be particularly relevant to the Usadel group.

### External Repository Requirements

| Package Name & Link | Critical quality criteria | Non-Critical quality criteria |
| -------------| -------------------------- | ------------------------------ |
|**pride** <ul><li>https://avpr.nfdi4plants.org/package/pride </li><li>validates if your ARC contains all necessary metadata to be publishable to PRIDE. | <ul><li>Investigation has title and description </li><li>Investigation has Keywords comment in correct format </li><li>All persons in Investigation Contacts must have a first name, last name, affiliation and valid email </li><li>Study has protocol, tissue & species in correct format </li><li>Assay has protocol, technology type, instrument model, and fixed and/or variable modification in correct format | |
| **edal** <ul><li>https://avpr.nfdi4plants.org/package/edal </li><li>validates if your ARC contains all necessary metadata to be publishable to e!DAL. | 

### ARC quality

| Package Name & Link | Critical quality criteria | Non-Critical quality criteria |
| -------------| -------------------------- | ------------------------------ |
| **plant-growth** <ul><li>https://avpr.nfdi4plants.org/package/plant-growth </li><li>Validates if the ARC contains the necessary metadata to describe conditions for plant growth. | ARC contains an annotation table with protocol type "Plant Growth Protocol" and if it exists, whether it contains the following fields: <ul><li>organism (OBI:0100026) </li><li>growth day length (DPBO:0000041) </li><li>light intensity exposure (PECO:0007224) </li><li>temperature day (DPBO:0000007) </li><li>temperature night (DPBO:0000008) | It is not critical that the annotation table contains <ul><li>genotype (EFO:0000513) </li><li>study type (PECO:0007231) </li><li>Reference Time Point (NCIT:C82576) </li><li>growth plot design (DPBO:0000001) </li><li>plant growth medium exposure (PECO:0007147) </li><li>humidity day (DPBO:0000005) </li><li>humidity night (DPBO:0000006) </li><li>plant nutrient exposure (PECO:0007241) </li><li>abiotic plant exposure (PECO:0007191) </li><li>biotic plant exposure (PECO:0007357) </li><li>watering exposure (PECO:0007383) |

### **CEPLAS Packages** 
Even if you are not a member of CEPLAS, there are number of packages available that can support in ensuring your ARC is as complete and descriptive as possible

| Package Name & Link | Critical quality criteria | Non-Critical quality criteria |
| -------------| -------------------------- | ------------------------------ |
| **ceplas-experimental** <ul><li>https://avpr.nfdi4plants.org/package/ceplas-experimental </li><li>Validates whether the ARC contains the minimal metadata to meet the CEPLAS quality criteria for a typical experimental ARC. |  <ul><li>ARC contains README and a LICENSE file </li><li>Investigation contains a title, description, at least one contact </li><li>Contacts contain first name, last name, email, affiliation, ORCID </li><li>At least one investigation contact has email and affiliation </li><li>ARC contains at least one study or one assay </li><li>Every study must contain at least one annotation table </li><li>Every assay must contain at least one annotation table </li><li>ARC contains 'raw' data (e.g. raw dataset file or URL) | <ul><li>Every investigation contact should have a valid email </li><li>Every investigation contact should have an affiliation </li><li>Every investigation contact should have an ORCID </li><li>At least one investigation contact should have role 'researcher' </li><li>At least one investigation contact should have role 'principal investigator' </li><li>Every study contains top-level metadata </li><li>Every assay contains top-level metadata </li><li>ARC annotation tables are connected </li><li>Every data entity should be derived from a Source or Sample </li><li>Every data entity should be annotated with at least one of Characteristic, Parameter, Factor </li><li>Every annotation table contains an Input </li><li>Every annotation table contains an Output </li><li>Every annotation table contains a ProtocolREF column |
| **ceplas-01-investigation** <ul><li>https://avpr.nfdi4plants.org/package/ceplas-01-investigation </li><li>Validates whether the ARC contains the minimal metadata to meet the CEPLAS quality criteria only on investigation level. | <ul><li>ARC contains README </li><li>ARC contains any LICENSE file </li><li>Investigation contains a title, description and contact </li><li>All investigation contacts contain first name and last name </li><li>At least two investigation contacts contain an affiliation and valid email | <ul><li>ARC contains README in recommended file format: README.md ARC contains LICENSE file in recommended file format: LICENSE </li><li>Every investigation contact should have a valid email </li><li>Every investigation contact should have an affiliation </li><li>Every investigation contact should have an ORCID </li><li>At least one investigation contact should have role 'researcher' </li><li>At least one investigation contact should have role 'principal investigator'|
| **ceplas-02-biometadata** <ul><li>https://avpr.nfdi4plants.org/package/ceplas-02-biometadata </li><li>Validates the ARC's "biological" metadata. | <ul><li>ARC contains at least one study, assay, workflow or run </li><li>ARC contains any annotation column (Characteristic, Parameter, Factor) </li><li>Every study contains at least one annotation table </li><li>Every study annotation table contains basic information </li><li>Every study annotation table column contains values </li><li>Every study annotation table row contains values </li><li>Every assay contains at least one annotation table </li><li>Every assay annotation table contains basic information </li><li>Every assay annotation table column contains values </li><li>Every assay annotation table row contains values </li><li>Every run contains at least one annotation table </li><li>Every run annotation table contains basic information </li><li>Every run annotation table column contains values </li><li>Every run annotation table row contains values | <ul><li>Every study contains a title </li><li>Every study contains a description </li><li>Every study contains contacts </li><li>Every assay contains a title </li><li>Every assay contains a description </li><li>Every assay contains performers </li><li>Every assay contains a measurement type </li><li>Every assay contains a technology type </li><li>Every assay contains a technology platform </li><li>Every workflow contains a title </li><li>Every workflow contains a description </li><li>Every workflow contains contacts </li><li>Every run contains a title </li><li>Every run contains a description </li><li>Every run contains performers </li><li>Every run contains a measurement type </li><li>Every run contains a technology type </li><li>Every run contains a technology platform </li><li>Every annotation table contains some annotation column |
| **ceplas-03-biodata** <ul><li>https://avpr.nfdi4plants.org/package/ceplas-03-biodata </li><li>Validates the ARC's "biological" data (e.g. measured, raw or processed, datasets). | <ul><li>ARC contains 'raw' data (e.g. raw dataset file or URL) </li><li>ARC assay dataset file exists | <ul><li>Every data entity derives from a Source or Sample </li><li>Every data entity is annotated with at least one of Characteristic, Parameter, Factor |
| **ceplas-04-connectedData** <ul><li>https://avpr.nfdi4plants.org/package/ceplas-04-connectedData </li><li>Validates whether data and metadata in the ARC are properly connected. | <ul><li>Every annotation table contains an Input </li><li>Every annotation table contains an Output </li><li>Every annotation table contains a Protocol reference </li><li>ARC annotation tables are connected | |
