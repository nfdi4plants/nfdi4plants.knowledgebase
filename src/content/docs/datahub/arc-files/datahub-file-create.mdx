<Steps>

1. From the [ARC panel](/nfdi4plants.knowledgebase/datahub/navigation-settings/datahub-arc-panel), navigate to subdirectory of your ARC. 

    ![](@images/datahub/datahub-add-files.drawio.png)

2. Click the plus sign next to your ARC's name (1).
3. Select New file.
4. This will open a new dialog where you can create your file.

    ![](@images/datahub/datahub-add-files-create.drawio.png)

5. Name the file (e.g. `README.md`) (1), 
6. add some text (2),
7. and commit the changes (3) with a commit message in the next dialog.

</Steps>
