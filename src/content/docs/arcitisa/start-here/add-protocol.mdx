<Steps>

1. Expand the folder of the study `AthalianaColdStress`

2. Right-click on the `protocols` folder and select `Open Folder Location` from the context menu.

    <img src={Protocol.src} width="50%"/>

3. Move the file `growth_protocol.md` from the demo data into the `protocols` folder.

    :::tip
    Alternatively, you can use the "Import files" function to import files into your ARC.
    :::

4. The file is added to your ARC and can be edited via ARCitISA

    <FileTree>
    - AthalianaColdStressSugar
    - studies
        - AthalianaColdStress
        - protocols
            - **growth_protocol.md**
    - ...
    </FileTree>

    :::note 
    In this example Viola has prepared a Markdown file (.md) as a protocol. 
    For a markdown guide, check out: <a href="https://www.markdowntutorial.com/" target="_blank"> https://www.markdowntutorial.com/ </a>
    :::

5. A click on the protocol's file name opens a text editor in the right panel.

</Steps>
