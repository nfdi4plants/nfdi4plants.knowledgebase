There are three options to use ARCitISA

### ARCitISA App

The standalone [ARCitISA App](/nfdi4plants.knowledgebase/arcitisa/installation) provides all features to work on your ARC, including

- Metadata annotation
- ARC design, file and folder handling
- Synchronization with the DataHUB 

:::tip
This is recommended for most users.
:::

---

:::note
The following alternatives only provide the ARCitISA features for metadata annotation.  
They do not support ARC design or DataHUB synchronization.
:::

### Alternative 1: Excel add-in

ARCitISA is available as an [Excel add-in](/nfdi4plants.knowledgebase/arcitisa/features/annotate-in-excel/) for both browser and desktop installations of Excel

- This is **recommended for users who prefer using Excel functionality** (e.g. for large amounts of metadata)
- Using the add-in with Excel Desktop allows to directly work on the ISA metadata workbooks (`isa.investigation.xlsx`, `isa.study.xlsx`, `isa.assay.xlsx`) in a local ARC.

### Alternative 2: Browser tool

ARCitISA is offered as a standalone [browser tool](https://swate.nfdi4plants.org/).

- This allows to use ARCitISA without any installation
- However, there is no direct communication with your ARC – you have to upload / download the files manually.
- This is recommended **to create and contribute [ARCitISA templates](/nfdi4plants.knowledgebase/ARCitISA/ARCitISA-template-contribution)**
