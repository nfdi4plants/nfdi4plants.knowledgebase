**ARCitISA** is a cross-platform app to create and manage your ARCs and synchronize them with the DataHUB.

- Please install the ARCitISA following [these instructions](/nfdi4plants.knowledgebase/arcitisa/installation)

:::caution[WIP: ARCitISA ~ SwateApp]
ARCitISA is still under development. Some features are not yet implemented and the app may contain bugs. Please report any issues you encounter to the data stewards. As of October 2026, the ARCitISA app is currently still called "SwateApp". The name will be updated in future releases.
:::
