<Steps>

1. In the file tree, right-click the `SugarsPhotometer` assay and select `Add Datamap`
2. Open the `isa.datamap.xlsx` file from the file tree or select the `DataMap` sheet at the table bottom
3. Open the "Data Annotator" <Icons.DataAnnotator /> tool on top and select the same file (`sugar_result.csv`) as before.
4. This time **select all 7 columns** and click `Add selectors`
5. Add 7 rows to the table, and `Insert selectors` to the `Input [Data]` column.
6. Add the following annotation to describe the columns in "sugar_result.csv"
    
    <ViolaSays>
      The first column of my result table "sugar_result.csv" contains the name of the measured sugar, that is the **molecule name**. 
      The other six columns contain the measured data: **molecule count** in mmol / kg. 
    </ViolaSays>
