In October 2026, we are launching **ARCitISA**, the successor to ARCitect and the new main application for creating and managing your ARCs.

## ARCitISA – What’s new?

- **Improved stability and performance** for a smoother user experience.
- **Work with multiple ARCs in parallel**, making it easier to switch between projects.
- **Simplified handling of data files**, whether large or small.
- **A new notes feature** lets you jot down thoughts, reminders, and other information that doesn’t yet have a dedicated place in your ARC.
- **Updated DataHUB authentication** for accessing the DataHUB.

## Already working with ARCs?

**The tool is changing, but the ARC concept is not!** You can continue working with ARCs created using ARCitect or ARC Commander.

- **A familiar and intuitive workflow:** We have designed ARCitISA to make the features you need easy to find and use.
- **A separate Git installation is now required on Windows:** Unlike the previous ARCitect installation, ARCitISA no longer bundles Git and Git LFS. You will need to install both separately if they are not already installed on your system.

## Things to keep in mind

- **Tested across different environments:** Data stewards and developers have tested ARCitISA on different operating systems.
- **Environment-specific issues may still occur:** Depending on your setup, including your operating system and the versions of Git and Git LFS installed, you may encounter errors. Please [reach out to Data Stewards for support](https://nfdi4plants.org/support/). 
- **Back up your work regularly:** We recommend committing and syncing your changes to the DataHUB frequently to keep your ARC safely backed up.

:::note[ARCitect support is being phased out]
You can continue using ARCitect, but active support will be discontinued. No further bug fixes or new features will be provided. We therefore recommend switching to ARCitISA.
:::
