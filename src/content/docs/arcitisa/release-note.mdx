In October 2026 we release the new app **ARCitISA** as the successor of ARCitect and major app for users to work on their ARCs.

## ARCitISA – What's new?

- Overall improved stability and performance
- You can now work on multiple ARCs in parallel
- Facilitated handling of large and small dataset files
- Option to add `notes` for anything you want to scribble down, that might not have a place, yet
- Updated DataHUB authentication

## If you have created ARCs before

- The tool changes - the ARC does not: You can keep working on your ARCs created before with other tools (ARCitect, ARC Commander).
- We are confident that you will find ARCitISA intuitive to use and that all features you need are easy to find. 
- Windows Git Installation: The previous ARCitect installation on Windows included Git and Git-LFS. These need to be installed separately now.

## Points to consider

- The tool has been tested by data stewards and developers on different operating systems.
- Depending on individual user setups (e.g. the versions of the operating system or Git and Git-LFS) you may still run into errors.
- In any case we recommend to store, commit and sync your changes frequently to the DataHUB to have a save backup of your ARC.

:::note
Although you can keep working with ARCitect, the support will fade out.
There will be no bug fixes or additional features.
:::
