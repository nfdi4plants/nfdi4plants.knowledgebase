## Installing Git and Git LFS

:::note
ARCitISA depends on <a href="https://git-scm.com/downloads" target="_blank">Git</a> and <a href="https://git-lfs.com" target="_blank">Git LFS</a>. If not already installed, these need to be installed separately.
:::

## Installing ARCitISA

<Tabs syncKey="os">
    <TabItem label="Windows" icon='seti:windows'>

        <Steps>
        1. Head to the ARCitISA's GitHub [release page](https://github.com/nfdi4plants/swate/releases/latest).
        2. Under "Assets" download the latest release for Windows (`ARCitISA-x.x.x Setup.exe`).
        3. In Windows Explorer, start `ARCitISA-x.x.x Setup.exe` to install `ARCitISA`

        6. Once started, you see a Windows Defender warning. To proceed, click `More info` and then `Run anyway`.

            ![](@images/arcitect/win-defender.png)

        7. Windows Defender Firewall further asks you to allow network communication. This enables communication with the [DataHUB](/nfdi4plants.knowledgebase/datahub).

            ![](@images/arcitect/win-firewall.png)

        </Steps>

    </TabItem>

    <TabItem label="macOS" icon="apple">

        <Steps>

        1. Head to the ARCitISA's GitHub <a href="https://github.com/nfdi4plants/swate/releases/latest" target="_blank">release page</a>.

        2. Download the macOS installer `ARCitISA-x.x.x.dmg` for your platform (Intel: x64 or Apple Silicon: arm64).

        3. Double-click the installer `ARCitISA-x.x.x.dmg` and move the app to your Applications folder.

        </Steps>

        ## Unidentified developer

        When starting ARCitISA for the first time, you are warned about an unidentified developer.

        <img src={MacOSPopup.src} style="width:25%;display: block; margin: 20px" />

        Please navigate to the Privacy & Security panel in your System Settings to `Open Anyway`.

        <img src={MacOSSecurity.src} style="width:50%;display: block; margin: 20px" />


        ## Accept incoming network connections

        Every time you start the ARCitISA, you are asked to accept incoming network connections.

        <img src={MacOSPopupNetwork.src} style="width:25%;display: block; margin: 20px" />

        This enables communication with the [DataHUB](/nfdi4plants.knowledgebase/datahub).

    </TabItem>

    <TabItem label="Linux" icon='linux'>

        <Steps>

        1. Install additional dependencies via
            
            ```bash
            sudo apt-get update
            sudo apt-get install libgtk-3-0 libnotify4 xdg-utils libsecret-1-0
            ```

            :::note
            On some linux distributions you have to run `sudo apt --fix-broken install` afterwards.
            :::

        2. Head to the ARCitISA's GitHub <a href="https://github.com/nfdi4plants/swate/releases/latest" target="_blank">release page</a>.
        3. Download the Linux DEB package `ARCitISA-x.x.x_amd64.deb`.
        4. Install ARCitISA

            ```bash
            sudo dpkg -i ./ARCitISA-x.x.x_amd64.deb
            ```

        5. Start the ARCitISA via

            ```bash
            arcitisa
            ```

            :::note[Admin privileges]
            `apt-get install` and `dpkg -i` often require admin privileges, since they write into system directories. You can circumvent this problem by local installations in folders where you have permission, e.g.

                ```
                dpkg-deb -x ./ARCitISA-x.x.x_amd64.deb $HOME/arc
                ```

                would install the ARCitISA in a folder in your home directory. You can then add it to your path via

                ```
                export PATH="$HOME/arc/ARCitISA:$PATH"
                ```

                To install `git`, `git-lfs`, `libgtk-3-0`, `libnotify4`, `xdg-utils` and `libsecret-1-0`, if they are not already installed, you can use `apt download`, which gives you the `.deb` files for their installations.  
                From there you can proceed the same as written above for the ARCitISA. `apt download` does not resolve package dependencies, so you may have to resolve them manually.

            :::



        </Steps>
