**ARCitect-GX** is a cross-platform app to create and manage your ARCs and synchronize them with the DataHUB.

- Please install the ARCitect-GX following [these instructions](/nfdi4plants.knowledgebase/arcitect-gx/installation)

:::caution[WIP: ARCitect-GX ~ SwateApp]
ARCitect-GX is still under development. Some features are not yet implemented and the app may contain bugs. Please report any issues you encounter to the data stewards. As of August 2026, the ARCitect-GX app is currently still called "SwateApp". The name will be updated in future releases.
:::
