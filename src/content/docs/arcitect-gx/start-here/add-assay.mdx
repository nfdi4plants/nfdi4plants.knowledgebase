import { Steps } from '@astrojs/starlight/components';
import { FileTree } from '@astrojs/starlight/components';

<Steps>

1. Click on the plus icon next to `assays` to add a new assay.
2. Enter an identifier for the `New Assay`.

    <ViolaSays>
        SugarMeasurement
    </ViolaSays>

3. Click `Create Assay`.
4. ARCitect-GX adds the assay `SugarMeasurement` including the folders `dataset` and `protocols` as well as a `README.md` and the `isa.assay.xlsx` workbook. You can display the file structure created by ARCitect-GX by clicking on `SugarMeasurement` as shown below.

    <FileTree>
    - assays
        - **SugarMeasurement**
            - dataset
                - ...
            - protocols
                - ...
            - isa.assay.xlsx
            - README.md
        - ...
    </FileTree>

    {/* :::note
    The `isa.assay.xlsx` is not displayed inside ARCitect-GX.
    ::: */}

5. Click on the assay's name (`SugarMeasurement`) in the file tree to open the folder
6. Click on the `isa.assay.xlsx` workbook to edit the assay metadata in the right panel.
6. Here you can add metadata about your assay.

    ![](@images/arcitect-gx/assay.png)

    <ViolaSays>
        Ok, so my **measurement type** is "sugar measurement". 
        And to specify the device I used for my measurement, I add "photometry" and "Infinite M200 plate reader (Tecan)" as the **technology type** and **technology platform**, respectively.
    </ViolaSays>

</Steps>
