<Steps>

1. Start the **ARCitect-GX** app.
2. In the dropdown on top click on "Create new ARC".
    
    ![](@images/arcitect-gx/new-arc.png)


3. Select an identifier for your ARC.

    <ViolaSays>

    To keep it simple, I call my ARC "AthalianaColdStressSugar"

    </ViolaSays>

    :::tip
    - Use a short acronym  
    - Avoid spaces and special characters in your ARC's name
    - Avoid administrative metadata (name, data, etc.)
    - Use a combination of keywords, maybe a grant number
    :::

4. Click `Create new ARC`
5. Select a location and click "open".
6. ARCitect-GX creates the base ARC folder on your computer and opens it right away.
  
    <FileTree>
    - AthalianaColdStressSugar
      - **assays**
      - **notes**
      - **runs**
      - **studies**
      - **workflows**
      - isa.investigation.xlsx
    </FileTree>

    {/* :::note
    The `isa.investigation.xlsx` is not displayed inside ARCitect-GX, but can be accessed by clicking on "AthalianaColdStressSugar" (in Viola's example).
    ::: */}

</Steps>
