<Steps>

1. Start the **ARCitect** app.
2. In the sidebar on the left, click on <QIcon name="note_add" /> `New ARC`.
3. Select a location and name for your ARC.

    <ViolaSays>

    To keep it simple, I call my ARC "AthalianaColdStressSugar"

    </ViolaSays>

    :::tip
    - Use a short acronym  
    - Avoid spaces and special characters in your ARC's name
    - Avoid administrative metadata (name, data, etc.)
    - Use a combination of keywords maybe grant number
    :::

4. ARCitect creates the base ARC folder on your computer and opens it right away.
  
    <FileTree>
    - AthalianaColdStressSugar
      - **studies**
      - **assays**
      - **workflows**
      - **runs**
      - isa.investigation.xlsx
    </FileTree>

    :::note
    The `isa.investigation.xlsx` is not displayed inside ARCitect, but can be accessed by clicking on "AthalianaColdStressSugar" (in Viola's example).
    :::

</Steps>
